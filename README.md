# 🚔 Crime Data Analytics Dashboard

## 📌 Project Overview

This project focuses on **analyzing crime data using Power BI** to uncover meaningful patterns, trends, and insights that can support **data-driven decision-making**.
Raw crime records are transformed into **interactive dashboards** that help understand crime distribution across **time, location, and crime categories**.

The goal of this project is to demonstrate **end-to-end data analytics skills** — from data collection and preprocessing to visualization and insight generation.

---

## 🎯 Objectives

* Analyze crime trends over multiple years
* Identify **high-crime regions and hotspots**
* Understand crime patterns by **type, location, and time**
* Build **interactive dashboards** for easy exploration
* Convert raw data into **actionable insights**

---

## 📊 Dataset Information

* **Source:** Kaggle – Crime Dataset
* **Format:** Multiple Excel / CSV files
* **Data Includes:**

  * Crime type/category
  * Year & time period
  * State / district / region
  * Crime counts and related attributes

> The dataset represents real-world crime records and is suitable for exploratory and descriptive analytics.

---

## 🔧 Tools & Technologies Used

* **Power BI** – Data modeling & dashboard creation
* **Microsoft Excel** – Initial data cleaning and preprocessing
* **DAX (Basic)** – Measures, calculated columns, KPIs
* **Data Analytics Concepts** – EDA, trend analysis, comparisons

---

## 🔄 Project Workflow

1. **Data Collection**

   * Downloaded crime datasets from Kaggle

2. **Data Cleaning & Preprocessing**

   * Removed duplicates and irrelevant columns
   * Handled missing and inconsistent values
   * Standardized column names and formats

3. **Exploratory Data Analysis (EDA)**

   * Analyzed crime distribution by year, state, and category
   * Identified trends and outliers

4. **Data Modeling**

   * Established relationships between tables
   * Created calculated columns and measures

5. **Dashboard & Visualization**

   * Bar charts, line charts, maps, and KPI cards
   * Slicers for interactive filtering
   * Aesthetic and user-friendly dashboard design

---

## 📈 Key Insights

* Crime trends vary significantly across **regions and years**

* Interactive filtering enables quick comparison and analysis
